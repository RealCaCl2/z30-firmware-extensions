# v22：细黄线与端部调整

> 最新反馈：v22 减细导致双线复现。新增 [v23](aspect-border-caps.md)，恢复长边参数 8、保留短端帽 2；实机效果未确认。以下为历史版本记录。

日期：2026-10-18。用户照片确认 v21 已变成单条黄线，但窄画幅竖线端部和宽幅框角有突出；用户同时要求线条稍细。

v21 对长边与短边统一使用线宽参数 8。v22 按矩形朝向分别提交参数：竖条为 `(6, 2)`，横条为 `(2, 6)`，目标是长边稍细、短边端帽缩小。这是根据照片和两个独立笔画字段作出的试验调整，原厂硬件的精确覆盖规则尚未恢复，不能把字段值直接当作屏幕上的像素宽度。

投影和 8 像素矩形边界保持 v21，仍满足原厂最小尺寸与偶数约束。白色网格、成片、取景拟合、通道占用/恢复及对焦记录处理不改。矩形构造器比较对齐后的宽高选择朝向。
