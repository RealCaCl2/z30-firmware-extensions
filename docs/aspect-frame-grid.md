## 范围映射

窄画幅 L 的源矩形分别是 `(308,0,4952,3712)`、`(464,0,4640,3712)`。原厂取景快照提供当前 viewport，v16 窄幅显示路径保留原厂 area 2，其 DX 源窗口缓存为 `(0,292,5568,3420)`；完整 DX 过渡窗口 `(0,0,5568,3712)` 也接受。

对每个边界使用整数投影：

```text
screen_x = viewport_left + (photo_x - source_left) * viewport_width / source_width
screen_y = viewport_top  + (photo_y - source_top)  * viewport_height / source_height
```

源窗口为未初始化或不在上述已确认的两类范围时，不写自定义参数，保留原厂网格。不据猜测支持放大、其他传感器窗口或未知显示状态。其他四种宽画幅保留旧版内接框的范围策略，仅补上内部参考线，避免将窄幅的源窗口假设扩展给它们。

举例：合成 viewport `(0,36,720,442)`、源窗口 `(0,292,5568,3420)` 下，4:3 的左右边界应约为 x=40 与 x=680，5:4 约为 x=60 与 x=660。旧内接法会把窄画幅框缩得更窄。该 viewport 是模型输入，不是新取得的实机测量。

完整 photo rect 可以超出 viewport。先按完整成片生成边界及内部等分线，再丢弃屏外的线，最后裁剪线段长度；不能把屏外上/下边界夹紧到可见窗口边缘，否则会生成假的裁切框。
