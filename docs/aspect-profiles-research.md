# Z30 多画幅：原厂几何通路实验

日期：2026-10-17。基于用户确认的 4:3、5:4、2:1、2.35:1、2.39:1，加上 XPAN 65:24。

后续已实现同一菜单内的运行时切换与参考框驱动实验，见[多画幅菜单与取景参考框](aspect-profiles.md)。下文保留独立几何实验的早期范围。

## 当前结果

**六组独立研究构建已通过原厂 ARM 函数的几何验证；没有新增相机菜单选项，也没有验证拍摄成片。** 每个构建单独借用原厂 area 2，不支持在一个构建中同时切换六种比例。现阶段不纳入 `full` 或日常构建，不作为可刷更新包交付。

以 DX 大尺寸 `5568×3712` 为名义最终照片坐标，取最大居中矩形。需要量化的边按最近的 8 像素取整，等距时向下，且限制在源图范围内。该步长是研究策略，不是已证明的 ISP 全部对齐合同。

| 比例 | L 候选 | M 候选 | S 候选 | L 名义裁切 |
|---|---|---|---|---|
| 4:3 | 4952×3712 | 3712×2784 | 2472×1856 | 左右各 308 |
| 5:4 | 4640×3712 | 3480×2784 | 2320×1856 | 左右各 464 |
| 2:1 | 5568×2784 | 4176×2088 | 2784×1392 | 上下各 464 |

量化后部分尺寸不严格等于标称比例，每个 L/M/S 的误差已记录在验证报告的 `ratio_error_percent`。没有扩大视野或多张拼接。

## 实际执行与验收

- [构建工具](../tools/build_aspect_trials.py)：从同一份身份校验通过的原始 EG 生成六个独立实验，每次修改均记录原值、新值和地址。
- [验证工具](../tools/verify_aspect_trials.py)：实际执行 `0x10142BEA` 缓冲区初始化、`0x1014237A` 配置生成、`0x101D5B36` 区域描述辅助函数，以及 `0x1020BFC8` 内部尺寸选择器。
- [验证报告](../build/research/aspect-trials/native-verification.json)：9 个原厂对照，加六组各 9 个案例，共 **63 个通过**。每组覆盖 area 0/2/4 × L/M/S。

验证范围：

1. 原始输入哈希与 CRC 检查，候选等长、CRC residue 为 0；字节改动严格限制在报告列出的表项和末尾 CRC。
2. 实际原厂函数返回，并保留栈与被调用者保存寄存器。缓冲区对齐尺寸不小于输出尺寸。
3. 修改后的输出尺寸、配置对象输出尺寸、裁边后的全分辨率区域一致。
4. 合并配置对象的起点与裁边量后，实际生成的坐标等于 `(16+x,8+y)`；相对于名义 DX 图像，上下/左右边距对称。
5. 内部区域保留既有大尺寸边缘像素：`(W+32,H+16)`；区域描述中对应内部偏移为 `(x,y)`。描述矩形不超出其内部区域。
6. 每个实验中，area 0 和 area 4 的缓冲区、配置对象、区域描述字节及内部尺寸选择器结果与原厂对照完全一致。这里只证明这些合成执行路径，不推出所有共享表消费者都无影响。

复现：

```powershell
python tools/build_aspect_trials.py
python tools/verify_aspect_trials.py --deps build/verify-deps
```

`--deps` 指向本地已有 Unicorn/Capstone 的目录。每个比例的 `research.eg.bin` 和 `research.json` 位于 `build/research/aspect-trials/<profile>/`。这些是模拟器研究输入，**不要安装到相机**。

## 新恢复的关键区别

宽幅主要改变高度和垂直偏移；窄于 3:2 的 4:3、5:4 还要恢复横向裁边。

`0x1014237A` 的正常合成照片分支保留一个全宽父区域，例如 `+0x22/+0x24 = 5568×3712`，随后从另一张表读取横向裁边到 `+0x38/+0x3A`，并计算 `+0x3C/+0x3E` 的裁边后宽高。因此不能要求父区域宽度直接等于最终输出宽度；也不能把 `+0x38/+0x3A` 误标成输出宽高。

4:3 大尺寸实测配置为：父区域 `5568×3712`，父起点 `(16,8)`，裁边 `(308,0)`，裁边后区域 `4952×3712`，最终输出同为 `4952×3712`。5:4 对应横向裁边 464。

本次关联表包括：

| 地址 | 本次用途 |
|---|---|
| `0x115A4D54` | area 2 内部区域偏移 |
| `0x115A4D78`、`0x115A4DF0` | 两个独立内部尺寸表，均需同步核对；此前 XPAN 单独构建没有覆盖前者 |
| `0x115A4DB4` | area 2 输出 L/M/S 尺寸 |
| `0x115A4E38` | 六个已观察到的区域变体条目；不是六个菜单选项 |
| `0x115A4EB0` | 对应边缘偏移变体 |
| `0x11571E30` | 正常照片分支三项横向裁边参数 |

窄幅实验参考 DX 表的边缘和变体差值；宽幅实验保留 16:9 表的相应差值。这是有原始数据依据的实验策略，尚未证明适用于所有拍摄模式。
