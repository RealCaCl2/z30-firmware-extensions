# 机内 LUT 真机测试清单

本页只覆盖「照片保存链套用 3D LUT」这一轮的实机测试。离线部分已通过：解析器、核心、会话、门控和镜像验证共 65 个案例，其中 6 个测试向量按字节一致激活（0 LSB 差），2 个负向向量按状态 3 拒绝并保留旧表。本页不声称任何实机结论；`camera_verified` 仍为 false。

## 这一轮要回答的四个问题

1. 保存链被 LUT 接管后，机身是否仍能正常生成副本（不崩、不丢原图、不写坏卡）。
2. 恒等表输出是否颜色中性。若不是，说明 BT.601 limited、Cb 在前、4:2:2 这三项假设中至少一项不成立。
3. SD 表能否加载：文本与二进制两条路径，以及负向文件是否被拒绝且保留旧表。
4. 全尺寸耗时是否可以接受。

## 菜单与状态文字

设置 → 自定义菜单 / Extensions → **照片 LUT**。四行动作：加载 SD LUT、使用内置 LUT、关闭并释放、运行状态。`*` 标出当前生效的动作，状态行同时出现在标题下和「运行状态」行。

| 状态文字 | 含义 |
|---|---|
| 已关闭 | 未启用，保存走原厂路径 |
| 内置 LUT | 使用镜像内嵌的 17³ 恒等表 |
| SD LUT 已就绪 | 已加载 SD 卡上的表 |
| 找不到文件 | 打开失败（状态 1），根目录没有 `WL-LUT.CUBE` |
| 访问文件失败 | 读写失败（状态 2） |
| 无效的 LUT | 解析失败（状态 3） |
| LUT 文件过大 | 容量越界（状态 4） |
| 内存不足 | 分配失败（状态 5） |
| 功能正在运行 | 宿主忙（状态 6） |

加载失败时保留此前生效的表与开关，只更新状态文字。

## 准备

- 一张可丢弃的存储卡，由相机格式化。
- 原厂 `Z_30_0120.bin` 用于回刷。
- 秒表或手机计时。
- 本页的记录表。

修饰入口不在设置菜单里：回放一张**本机拍摄的 JPEG**，按 `i` 键，菜单里选「修饰」，再选**「单色」**——它打开后有三个变体，任选其一。**不要用 D-Lighting**：钩子挂在内部索引 6 的处理函数（`0x1025FB8E`）上，那是「单色／棕褐／青色」这一族（操作码 5/6/7）；D-Lighting 是操作码 1 → 内部索引 0，走的是另一个处理函数，钩子不在那条路上，点了只会得到原厂 D-Lighting。判读方式是「灰图还是彩色图」：LUT 未接管时单色输出灰／棕褐／青色，LUT 接管后输出红蓝互换的彩色图——单色在这里恰好是最灵敏的判读项。按官方手册 09-07，修饰处理的是已有照片，结果另存为新文件，原图保留——**没有单独的「保存副本」命令，确认修饰本身就是另存**。电脑修改过或别的设备拍的图片可能无法修饰。

## 失败判读

| 现象 | 可能原因 | 下一步 |
|---|---|---|
| 菜单进不去或崩溃 | 页槽、宿主或内存 | 回刷原厂，保留现象描述 |
| 用 swap 表输出与原图完全相同 | 门控未触发，或该修饰项没走这个处理入口 | 确认状态为「SD LUT 已就绪」、修饰项确实是「单色」（不是 D-Lighting）；仍不变则说明激活单元没写进去，需要探针镜像 |
| 输出灰但整体偏亮或偏暗 | 范围不匹配（full 与 limited） | 改 `src/z30_extensions/lut.py` 的 `Y_OFFSET`/`Y_SPAN` |
| 输出灰但带色偏 | Cb/Cr 顺序或矩阵系数错 | 改 `src/z30_extensions/lut.py` 的平面顺序与系数 |
| 副本缺失或保存失败 | 门控或阶段传播 | 保留现象，回退原厂 |
| 单张耗时超过两分钟 | 标量实现性能不足 | 下一版做 NEON 或分块 |
| 加载后立刻崩溃 | 堆不足 | 先只测 17³ 文本，暂不测 33³ |
| 声音相关现象 | 镜像同时含快门声音框架 | 与本轮无关，单独记录 |

## 交回

每步的状态文字与耗时、输出 JPEG 与对应原图（同名），以及崩溃时的现象描述。有了 `luma-17.cube` 的结果就能定位色彩契约的偏差方向，改一处常数重出镜像即可。

## 已知限制

- 色彩契约（BT.601 limited、Cb 在前、4:2:2）未在设备上验证，恒等表本身可能已有偏色。
- 全尺寸耗时未测，标量 Thumb-2 实现预计在数十秒量级。
- 运行时分配器与文件 I/O 上下文仍属未证部分；本轮读取改为 `seek(END)` 取长度后分段定位读取，真机上 seek 是否对 SD 文件有效尚未验证。
- 读不满长度时报「访问文件失败」（状态 2），与「无效的 LUT」（状态 3）区分开，便于判读。
- 状态不跨断电持久化。
- 本工具不刷写相机，也不写物理卡。
