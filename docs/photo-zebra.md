# 照片取景斑马纹

`photo-zebra` 将原厂视频高光显示扩展到照片取景，复用原厂图案和八档阈值。默认 `full` 包含此功能，也可单独构建；单独选择会自动包含自定义菜单框架。

## 使用

1. 进入“自定义菜单 → 照片高光显示”，选择“开启”。英文菜单为 `Extensions → Photo zebra → ON`。
2. 在原厂高光显示设置中选择非关闭图案，并调整阈值。
3. 返回照片取景，亮部达到所选阈值时显示条纹。

照片开关默认关闭。关闭只恢复照片模式的原厂资格限制，不改变视频斑马纹，也不覆盖原厂样式和阈值。

选择保存到 SD 卡根目录的 `WL-ZEBRA.CFG`。重启后首次初始化自定义菜单时恢复；初始化前保持关闭。配置缺失或无效时保持关闭，保存失败会显示提示，当前内存选择仍然有效。

原厂场景、峰值对焦和其他显示限制继续生效。若没有显示，检查峰值对焦、高光图案和当前拍摄状态。手动曝光测试还应检查“将设置应用于即时取景”。预览阈值未标定为 NEF 饱和程度。

## 构建

```sh
python patch.py full --source path/to/Z_30_0120.bin --output output/EG209020.BIN
python patch.py photo-zebra --source path/to/Z_30_0120.bin --output output/EG209020-photo-zebra.BIN
```

构建需要 Python 3.10+ 及汇编依赖，可先运行 `python -m pip install '.[sound]'`。输出目录须预先存在。输出是独立 EG 模块，使用项目既有加载流程。

## 验证范围

照片取景条纹、原厂阈值和开关，以及 JPEG/NEF 文件完整性已有机身验证，条纹未写入照片。独立照片开关尚待机身验证。

离线 ARM 检查覆盖 6,912 组输入、41,472 次原厂回调执行，包括关闭时与原厂行为一致、开启时保留场景/状态限制，以及视频行为一致。独立开关另有保存、恢复、无效配置和保存失败检查。

辅助 QEMU 检查覆盖简体中文、繁体中文、英文的原生菜单、触摸选择、返回和显示请求。其传感器预览为诊断模型，不能作为真实条纹像素或实拍文件证据。

修改仅涉及原厂高光资格回调和独立菜单设置；阈值换算、显示请求构造、照片图像数据路径和文件写入函数保持原厂实现。
