# 自定义电子快门声音

2026-10-17 状态更新：用户确认当前全部八项功能均已在 Nikon Z30 C 1.20 实机检验通过，包括多画幅、全信息页、声音配置记忆和机内码率档位。下文旧版本的待实机表述保留当时的测试范围，以本条为当前功能状态；离线工具的验证字段仍仅描述工具自身证据，不表示穷举全部模式、组合或故障条件。

v36 菜单分类更新见 [说明](aspect-mask-menu-v36.md)：包含画幅、码率或模块功能时，首页按用途分类，以下四项移入“快门声音”子菜单，确认文件/开关后返回该分组。本次层级更新有原生代码和三种语言的 QEMU 菜单验证，尚待机身确认；上文实机记录属于此前版本。

仅包含声音框架时，设置菜单增加 `Shutter sound`；包含其他自定义功能时入口为 `Extensions`。界面跟随机身语言，分别显示简体“快门声音 / 自定义菜单”、繁体“快門聲音 / 自訂選單”，其他语言使用英文。声音菜单英文标签为：

```text
Enabled          OFF / ON
Sound file       None / SHUTTER.WAV / 1.WAV..4.WAV
Preview sound
Reload sound
```

Enabled 打开 OFF / ON 选择页。Sound file 打开五个文件选择项。`*` 表示当前选项，选中后按一次 OK 应用并返回主菜单。选择文件不自动开启声音，不自动播放。

加载失败保留之前有效的声音及开关，使用独立提示页显示错误正文和“确定”按钮。确认或返回后回到发生错误的页面，标题始终保持菜单名称。Preview sound 为显式预听，Reload sound 重新读取当前文件。

## 声音触发与文件

没有有效保存记录时默认 OFF。需开启本功能并开启相机原厂静音拍摄，才在静音照片拍摄时触发自定义声音；录像和非静音照片不触发。预听可在 OFF 时使用。

成功选择文件或改变开关后，将开关和文件编号保存到 SD 卡根目录 `WL-SOUND.CFG`。记录为 16 字节：版本标识 `WLS1`、开关、编号 0–4，以及前三个字段异或值的按位取反。重启后在首次进入菜单或首次照片触发时读取记录；此前启用的声音会重新加载，无需先打开自定义菜单。声音文件必须仍在同一张卡的原路径。恢复失败保持关闭，配置文件损坏或不存在时使用默认状态。首次拍照可能增加一次 SD 读取的延迟。

保存检查写入字节数和关闭状态；失败显示“设置保存失败”，当前 RAM 中的声音仍可使用，但不能认为已经保存。异常关闭保留文件句柄供后续重试，避免重复打开泄漏。写入中断可能留下无效记录，下次恢复会拒绝该记录并保持关闭。此功能的指令级及辅助 QEMU 结果见 [UI 验证记录](ui-qemu.md)，实际断电、拔卡及播放效果尚待实机确认。

支持 SD 卡根目录 `SHUTTER.WAV` 和 `SHUTTER/1.WAV` 至 `SHUTTER/4.WAV`。格式为标准 44 字节 WAV 头、8000 Hz、单声道、16 位 signed little-endian PCM，非空、最长 1.08 秒，不包含额外 WAV 块。

已有声音文件的用户只更新固件即可，无需覆盖自己的 WAV。`tools/prepare_wav.py` 可规范化短 PCM 音频；脚本中的 example() 可生成原创示例。

## 菜单布局

- 使用普通子菜单 flags 及其标题/返回图标模板，模板从用户原始固件本地读取。
- 主菜单文件值栏宽度为 330 像素；Enabled 使用短标签，预听和重载标签保留整行宽度。
- 文件和开关选择页保留宽标签栏，用 `*` 替代易截断的 Selected。
- 主菜单和选择页标题使用固定菜单名称，预留右上返回图标空间；错误提示正文使用独立控件。
- 菜单控件 ID 从原始固件扫描核对，避开已用 ID。原厂方向/返回处理保留；确认处理仅作用于私有声音页和提示页。

声音菜单不注册 Camera Status 页面。声音状态使用原厂未使用的 page-0 RAM 指针位置锚定私有分配，该槽没有注册可见状态页面；初始化用原子锁防止菜单和照片任务重复分配。音频服务仍由原厂队列和完成回调管理，无新增线程。SD 写入仅用于上述声音配置文件，不修改 WAV 或相机照片。

## 离线检查的限制

离线工具可检查 WAV 校验与 PCM 转换。实际显示、触摸命中、文件读取和扬声器播放需要相机验证；方法与覆盖范围见 [验证说明](verification.md)。
