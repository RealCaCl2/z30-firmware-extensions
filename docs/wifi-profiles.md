# 可选扩大 Wi-Fi 配置覆盖

原 `wifi-5ghz` 只改配置 7 及未设置编号时的回落。
若机身选择其他有效编号，原预设不会改变该编号的无线请求。
`wifi-5ghz-all-profiles` 覆盖 Z30 C 1.20 的全部 22 个有效编号：1–10、14–25。

每条记录仅将国家代码和修订号从 `AA/原值` 改为 `US/-1`，
保留最后的原编号字段及其他 12 个保留槽，不写机身持久地区项。
构建前核对完整原厂表、输入身份及原字节；不新增运行代码。

```sh
python patch.py wifi-5ghz-all-profiles --source Z_30_0120.bin --output output/EG209020.BIN
python patch.py shutter-random wifi-5ghz-all-profiles --source Z_30_0120.bin --output output/EG209020-random-wifi.BIN
```

新预设不改变默认 `full`。显式同时选中原 `wifi-5ghz` 或 `full` 时，
由新预设覆盖无线部分，避免第 7 槽被重复修改；其他预设保持原有选择。

这只是无线国家配置请求覆盖，不等于全球所有信道开放，也未识别港版/国行的具体内部编号。
已有一台机身反馈扩大覆盖后能连接目标 5 GHz 热点，尚无逐信道或其他地区机身覆盖结果。
原厂另有绕过这张表的初始化分支，该路径保持原样。
有效信道、功率、2.4 GHz 兼容性及相机自身热点行为取决于驱动和硬件，
应按使用地点确认；不承诺提速、协商带宽或所有连接模式均改变。
